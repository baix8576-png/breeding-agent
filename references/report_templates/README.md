# report_templates

Owner: `popgen_quantgen`; shared report/audit entries owned by `orchestrator` and `safety_fuse`

Purpose:
- Store end-user report, diagnostic report, report index, and audit bundle templates.
- Support the `Artifact + Report` and `Audit + Memory` stages.

Formal knowledge files:
- `qc-report-template.md`: QC report section template and cautions.
- `structure-summary-template.md`: PCA/structure summary template and interpretation boundary.
- `genomic-prediction-template.md`: genomic prediction report template and performance caveats.
- `report_index_v2_template.md`: `report_index.v2` structure and traceability entries.
- `diagnostic_report_template.md`: diagnostic report and evidence table template.
- `audit_bundle_template.md`: audit bundle and manual confirmation record template.

Maintenance notes:
- Templates are not substitutes for validated analysis results.
- New formal Markdown files must include `knowledge_item.v2`.
