# docs

This directory stores project-level design notes, release notes, and architecture supplements
that do not belong in `README.md`, `AGENTS.md`, or repo-scoped skill definitions.

Key files:

- `HANDOFF.md`: mandatory continuity ledger with project-specific `HANDOFF v2` schema and resume checklist.
- `v2_system_map.md`: V2 current-stage system map, including inherited V1.5 execution kernel and V2 control-plane additions.
- `current_workflow_file_map.md`: current workflow-to-file responsibility map, script/domain alignment, and trusted execution boundaries.
- `genomic_agent_architecture_summary.md`: archived early architecture summary kept for historical context.
- `knowledge_update_workflow.md`: operational workflow for updating local knowledge assets and retrieval evidence-chain behavior.
- `pipeline_pack_integration_guide.md`: pack contract and integration checklist for blueprint packs under `src/pipeline/packs`.
- `tool_manifest_authoring_spec.md`: manifest authoring standards, validation rules, and regression expectations.
- `release_process_v2.md`: standardized release flow for version tags, production gates, and rollback baseline.
- `v2_0_final_acceptance_review.md`: V2.0 architect final-review checklist and gate commands.
